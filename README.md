# DSA-JavaScript

Practice problems and language fundamentals in vanilla JavaScript. Each file is a standalone script: it defines a function or class, runs a small example, and prints the result with `console.log`.

## Requirements

- [Node.js](https://nodejs.org/) (any current LTS is enough)

No install step. There are no dependencies.

## How to run

From the repo root:

```bash
node arrays/two-sum.js
node if-else/fizzbuzz.js
node stack/balanced-string.js
```

Replace the path with any file under the folders below.

## Topics

| Folder | What it covers |
| --- | --- |
| [`if-else`](if-else) | Conditionals, ternary, comparisons, and small decision problems (odd/even, greatest of three, profit/loss, FizzBuzz). |
| [`loops`](loops) | `for` and `while`, series, factorials, digit sums, factors, and ASCII. |
| [`methods`](methods) | Function syntax, return values, arguments, pass-by-value vs reference, and built-in helpers. |
| [`patterns`](patterns) | Nested-loop star, number, and alphabet patterns (triangles, pyramids, diamonds, spirals). |
| [`arrays`](arrays) | Array basics plus classic problems: two sum, max subarray, rotate image, set matrix zeroes, move zeroes, Pascal’s triangle, next permutation. |
| [`strings`](strings) | String methods, builders, palindromes, anagrams, compression, substrings, and character frequency. |
| [`recursion`](recursion) | Factorial, Fibonacci, powers, digit sums, palindromes, and printing natural numbers. |
| [`sorting`](sorting) | Bubble, selection, and insertion sort, plus sorted-array problems (union, common elements, kth smallest). |
| [`binary-search`](binary-search) | Binary search on a sorted array. |
| [`maps-and-sets`](maps-and-sets) | `Map` and `Set` for two sum, anagrams, distinct elements, pair counts, and longest non-repeating substring. |
| [`stack`](stack) | Stack operations, balanced brackets, min element, reverse, and sort. |
| [`linked-list`](linked-list) | Singly linked list, insertion, and list exercises. |
| [`collections`](collections) | Built-in collection APIs: arrays, maps, sets, stacks, queues, and linked lists. |
| [`oops`](oops) | Classes, constructors, `this`, inheritance, `super`, polymorphism, abstraction, and small class designs (fraction, complex number, array list). |
